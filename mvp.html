🌙 夜航 · MVP 测试版

定位 B（轻监测睡眠 App）｜ 手机放床头：陪你入睡 → 整夜记录 → 次日只改一件事

本版只保留验证核心假设所必需的功能，目标：跑通一次完整闭环，收集你的第一手反馈。

MVP 做什么（P0 必需）

  • 免穿戴记录：体动 → 浅睡/深睡/清醒 + 入睡/起床时间 + 夜醒次数
  • 助眠音景 + 自由混音，入睡自动停（检测入睡 → 10 分钟静默确认 → 30 秒淡出）
  • 鼾声 / 梦话触发式短录音（仅本机）+ 事件回放
  • 早报一屏：3 个数字 + 阶段图 + 一句人话解读
  • 干预闭环：每晚只推 1 个动作 → 次夜自动验证效果
  • 趋势：7 晚柱状 + 我的动作清单（有效 / 无效 / 数据不足）
  • 连续记录天数 + 可分享的早报卡片（不含分数与排名）
  • 无账号可用 · 数据仅本机 · 固定"非诊断"声明

建议这样测（跑通一次闭环）

  • ① 首次使用页选一个目标 → 点开始今晚
  • ② 播放器点 模拟入睡 → 看"入睡自动停"如何淡出
  • ③ 自动进入夜间记录 → 点 我醒了
  • ④ 早报：3 数字 → 阶段图 → 动作对比 → 鼾声回放 → 分享卡片
  • ⑤ 底部切到 趋势 与 我的，看动作清单与隐私声明

重点验证 3 个假设

  • 闭环成立吗：每晚 1 个动作 + 次夜验证，你愿意连续做几晚？
  • 减少焦虑吗：不评分 / 不排名 / 不逼打卡，是否反而更放松？
  • 鼾声回放有用吗：你愿意点开听、并据此改变行为吗？

本次未包含（放后续迭代）

  • 手机摆放校准（提升"体动 vs 噪声"区分度）
  • 睡前 30 分钟仪式编排
  • 睡眠天气 · 月亮盈亏 · 动作证据等级 · n-of-1 置信度块
  • 付费与会员（整夜鼾声回放、AI 深度解读）
  • 就医自查清单 · HealthKit · 桌面小组件 · Android

数据与隐私（大白话版）
不上传：鼾声/梦话原始录音、睡眠阶段逐分钟明细。这些只存在你手机里，删 App 即删。
会上传：去掉身份标识的分钟级运动统计与阶段标签，用于改进算法和生成早报解读。没有账号体系，只有设备级随机 ID。
没有：广告 SDK、第三方追踪 SDK、通讯录/相册权限。
你可以：随时一键删除全部数据；不联网也能用核心记录功能。
我们刻意把"会上传什么"说全，而不是只说"数据留在手机上"——这是我们对你这边的承诺。
删除全部数据？
本机录音、睡眠明细、动作清单都会被清除且不可恢复。云端只保留无法关联到你的匿名统计。
