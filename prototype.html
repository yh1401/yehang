🌙 夜航 · 交互原型

定位 B（轻监测睡眠 App）｜ 手机放床头：陪你入睡 → 整夜记录 → 次日只改一件事

快速体验（推荐动线）

  • 点 开始今晚 → 手机摆放校准 → 进入助眠播放器
  • 点 模拟入睡 → 看"入睡自动停"如何淡出
  • 自动进入 夜间记录 → 点醒来看早报
  • 早报里 → 睡眠天气 / 单变量实验 / 鼾声回放 / 分享卡片

本原型重点演示 3 件事

  • 入睡自动停：检测入睡 + 安静 10 分钟淡出，而非固定定时
  • 干预闭环：每晚 1 个动作 → 次夜自动验证效果 → 有效动作清单
  • 诚实口径：固定"非诊断"声明、鼾声误报提示、就医提示

本轮新增（实用 + 有趣）

  • 动作库证据等级：把"客观研究结论"与"对你个人是否有效"拆成两套标签，全赛道没人这么做
  • n-of-1 单变量实验：一次只改一件事，累计 3 次才下结论，附置信度进度
  • 睡前 30 分钟仪式：固定顺序的清单，完成即自动开始音景
  • 手机摆放校准：提升"体动 vs 风噪"区分度，且明确不承诺准确率
  • 睡眠天气：先给情绪、弱化数字，避免"睡眠分数焦虑"
  • 月亮盈亏：12 晚 = 一轮，替代连续打卡，断一晚不清零

数据与隐私（大白话版）
不上传：鼾声/梦话原始录音、睡眠阶段逐分钟明细。这些只存在你手机里，删 App 即删。
会上传：去掉身份标识的分钟级运动统计与阶段标签，用于改进算法和生成早报解读。没有账号体系，只有设备级随机 ID。
没有：广告 SDK、第三方追踪 SDK、通讯录/相册权限。
你可以：随时一键删除全部数据；不联网也能用核心记录功能。
我们刻意把"会上传什么"说全，而不是只说"数据留在手机上" —— 这是我们对你这边的承诺。
什么时候该去看医生
以下为一般性提示，不构成诊断。出现任一条，建议到睡眠门诊 / 呼吸科做专业评估。
1. 睡觉时被目击到呼吸暂停、憋气或突然憋醒
2. 白天严重嗜睡：开会、开车时打瞌睡
3. 鼾声响亮且伴晨起头痛、口干
4. 夜醒时伴心悸、胸闷
5. 血压长期控制不佳，同时打鼾
6. 失眠持续 ≥3 个月且明显影响白天功能
夜航不会给你下"你患有睡眠呼吸暂停"这类结论，只会提示"建议就医"。
